# controle de financas
Projeto simples para controle de receitas e despesas pessoais — feito com HTML, CSS e JavaScript, persistindo dados no browser via localStorage.

## 🧾 Sobre o Projeto

O Controle de Finanças é um aplicativo frontend leve que permite ao usuário registrar entradas (receitas) e saídas (despesas), visualizar o saldo atual e manter um histórico de transações.
Ideal para quem quer acompanhar seus gastos e rendas sem depender de planilhas externas ou softwares complexos.

## 📌 Funcionalidades
 * ✅ Adicionar transações como receita ou despesa (com descrição, valor, tipo).

 * ✅ Listar todas as transações registradas.

 * ✅ Exibir o saldo atual — total de receitas menos despesas.

 * ✅ Remover transações individuais.

 * ✅ Persistência dos dados no navegador com localStorage (os dados permanecem mesmo após atualizar a página).

## 🚀 Tecnologias Utilizadas

 * HTML
 * CSS (estilização / layout)
 * JavaScript puro (sem frameworks)
 * localStorage do navegador para persistência simples de dados

## 🔧 Como Executar Localmente

1 Clone o repositório

   git clone https://github.com/marcosoliveira253/controle-de-financas.git

2 Abra o arquivo index.html no seu navegador — não há necessidade de servidor ou build.

3 Comece a usar: adicione receitas e despesas e veja seu saldo.
